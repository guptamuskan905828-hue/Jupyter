# Basic Pandas Analysis

## Overview
This project demonstrates basic data analysis using the Python Pandas library. It includes data loading, cleaning, filtering, aggregation, and visualization techniques commonly used in data analysis workflows.

---

## Features
- Load CSV datasets
- Display dataset information
- Handle missing values
- Filter and sort data
- Perform statistical analysis
- Group and aggregate data
- Create simple visualizations

---

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
